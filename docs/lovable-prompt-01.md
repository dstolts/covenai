Build a stunning landing page for CovenAI (covenai.co) -- an open-source community engagement framework with gamification for AI builders. This is a static marketing/landing page with NO backend, NO auth, NO database.

## Brand Identity
- **Name:** CovenAI (one word, always)
- **Tagline:** "Build with AI. Earn your rank."
- **Mission:** "Grow together. Build with AI. Give back."
- **Aesthetic:** Medieval/mystical meets modern terminal/code. Think ancient order of builders, NOT witchcraft or Halloween. No pentagrams, no cartoon witches, no cauldrons. YES: geometric sigils, ancient runes, stone architecture, code brackets.
- **Voice:** Expert but never elitist. Fast-paced but not rushed. Mystical but grounded. Bold but not arrogant.

## Color Palette (STRICT -- use these exact values)
- **Primary background:** Dark slate #1E293B
- **Secondary background:** #0F172A (darker panels/sections)
- **Accent 1:** Deep purple #5B21B6 (CTAs, highlights)
- **Accent 2:** Gold #F59E0B (badges, tier accents, important elements)
- **Accent 3:** Emerald #10B981 (success states, tier 4)
- **Text primary:** White #FFFFFF
- **Text secondary:** #94A3B8 (muted descriptions)
- **Borders/dividers:** #334155

## Typography
- Headings: A bold sans-serif or geometric font. Section titles should feel authoritative.
- Body: Clean sans-serif, highly readable.
- Code/monospace elements: Use a monospace font for anything referencing code, tiers, or technical concepts.
- NO serif or blackletter fonts (keep it modern).

## Dark Theme ONLY
This site is dark theme only. No light mode toggle. The entire design is built on the dark slate palette above.

## Mobile-First
Most traffic comes from social media link clicks on phones. Every section must look great on mobile. No horizontal scrolling. Touch-friendly CTAs.
