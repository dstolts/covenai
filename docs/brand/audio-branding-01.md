# Audio Branding Strategy -- Claude Code Deep Dive Series
**Created:** 2026-03-24
**Status:** DRAFT -- needs Dan's approval on aesthetic direction

## The Concept: "Ancient Craft Meets Modern Code"
Medieval/folk audio + terminal/code visuals. The aesthetic contrast is inherently memorable -- nobody in tech content is doing this. Bardcore proved medieval-styled audio goes viral. Applying it to AI coding content is an untapped niche.

## Sonic Logo (3-5 seconds)
- Single distinctive instrument: lute, hurdy-gurdy, or hammered dulcimer
- Short melodic phrase (3 notes minimum) with one unexpected interval
- Subtle digital/glitch transition at the end (medieval -> code bridge)
- Must be recognizable in 2 seconds (Fireship test: can you ID the creator from audio alone?)

## Audio Cue Kit
| Cue | Sound | When |
|-----|-------|------|
| Intro sting | Medieval instrument motif (3-5s) | Every video open |
| Outro sting | Same motif, resolved/concluded | Every video close |
| Engagement sting | Short lute strum + bell | "Like/comment/follow" moments |
| Pro tip | Soft chime or harp pluck | Key insight moments |
| Code typing | Keyboard SFX (mechanical keys) | While typing commands in demo |
| Transition | Whoosh or subtle bass sweep | Between demo sections |
| Reveal | Bass hit + string swell | "And look what happens..." moments |
| Climax | Full folk motif (5-8s) | Challenge announcements, leaderboard reveals |

## Frequency Strategy
| Content Type | % of Videos | Audio Approach |
|-------------|-------------|----------------|
| Core tutorials | 60% | Original voice + minimal folk ambient background |
| Discovery/trending | 20% | Ride a trending sound with medieval sting bookends |
| Longer deep dives | 20% | Folk ambient underscore (lofi-medieval hybrid) |

## Platform Strategy
1. Record as "Original Sound" on TikTok FIRST -- creator attribution + algorithm preference for originality (65% of TikTokers prefer original sounds)
2. Same audio files on YouTube Shorts + IG Reels (own files, not platform libraries)
3. Captions/text hooks on ALL platforms -- most viewers start muted
4. The sonic logo travels with the content when reshared (TikTok watermark effect)

## Production Options (Ranked)
1. **AI-generated custom** (Soundverse, Beatoven, Suno) -- royalty-free, cross-platform safe, fast iteration. Generate 5 variations, A/B test. Cost: $0-30/mo.
2. **Commission from Fiverr/Upwork** -- custom medieval motif composed to spec. Cost: $100-300 one-time. Full ownership.
3. **Epidemic Sound + custom sting** -- subscription for background tracks ($15/mo), custom sting for logo. Covers TikTok + YouTube + IG under one license.
4. **License "One Tin Soldier"** -- expensive, limited platforms, not recommended for primary use. Could work as a one-time homage/reference in a specific video.
