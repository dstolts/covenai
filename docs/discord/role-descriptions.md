# Discord Role Descriptions and Colors
**Create roles in this exact order (top to bottom). Higher position = more power.**

---

## Staff Roles (Top of Hierarchy)

### @Guildmaster
- **Color:** #FF0000 (red)
- **Hoist:** Yes
- **Permissions:** Administrator
- **Description:** Server owner. Full control. Dan only.

### @Arcane
- **Color:** Bot default (no override)
- **Hoist:** No
- **Permissions:** Manage Roles, Send Messages, Embed Links
- **Description:** Leveling bot. Must be positioned ABOVE all tier roles in hierarchy.

### @Sentinel
- **Color:** #E74C3C (dark red)
- **Hoist:** Yes
- **Permissions:** Manage Messages, Timeout Members, View Audit Log
- **Description:** Community moderators. Trusted members who keep The Coven civil.

## Utility Roles (Bottom of Hierarchy)

### @Verified
- **Color:** None (no color)
- **Hoist:** No
- **Description:** Granted after onboarding completion. Required to access main channels and send messages.

### @Challenger
- **Color:** #FF6B35 (orange)
- **Hoist:** No
- **Description:** Opted into weekly challenge notifications. Assigned via #role-select or onboarding.

### @ShipWithClaude
- **Color:** #00D4AA (teal)
- **Hoist:** No
- **Description:** Active in the daily #ShipWithClaude challenge. Build with Claude Code. Post what you ship.

- **Color:** None (no color)
- **Hoist:** No
- **Description:** Opted into announcement pings. Toggle via #role-select.
