## 1. TIER PROMOTION (posted in #tier-ups by Arcane bot or manually)

### Arcane Auto-Message (configured in bot)
```
{user} has ascended to Level {level}. New rank: {reward}
```

### Manual Promotion Announcement (for special cases)
```
RANK UP

[username] has earned the rank of [Tier Name].

Points: [total]
New rank: [Tier] ([Badge symbol])
Unlocked: [key reward for this tier]

The Coven recognizes those who build and contribute. Well earned.
```

### Example
```
RANK UP

@sarah_builds has earned the rank of Sage.

Points: 780
New rank: Sage (Emerald eye)
Unlocked: Tool license + monthly Q&A access + Inner Circle

The Coven recognizes those who build and contribute. Well earned.
```

## 3. CHALLENGE LAUNCH (posted in #challenges every Monday)

### Weekly Challenge
```
WEEKLY CHALLENGE -- [Challenge Name]

Theme: [description tied to this week's content]

Rules:
  - [Specific task or constraint]
  - Post your entry in this channel with #ClaudeCodeGuild
  - Entries accepted until Friday midnight UTC
  - Must be your own work (AI-assisted is fine, AI-only is not)

Points:
  - Entry submitted: 25 pts
  - Top 3 finishers: 50 pts each
  - Winner (featured by Dan): 100 pts
  - First valid submission: +25 bonus

Winner announced next Monday. Best entries featured in Dan's video.

Good luck, builders.
```

### Monthly Challenge
```
MONTHLY CHALLENGE -- [Challenge Name]

Build something real with Claude Code this month.

Theme: [description]
Deadline: [last day of month] midnight UTC
Submit: Post in this channel with a repo link or demo

Judging criteria:
  - Creativity (does it solve a real problem?)
  - Utility (would someone else use this?)
  - Community value (did you document or teach it?)

Top 3 entries showcased in the monthly compilation video.
Winner receives [prize from tier reward pool].

Ship it.
```

### Seasonal Event -- Forge of Code (Quarterly)
```
THE FORGE OF CODE -- [Season] [Year]

90-day build challenge. Teams of 3-5.

The goal: build a complete project with Claude Code.

How to enter:
  1. Form a team (3-5 members) or request team placement in #general
  2. Register at covenai.co/teams with your repo URL
  3. Build for 90 days. Team points = sum of member points.
  4. Final submissions due [deadline]

Prizes:
  - Winning team: group coaching session with Dan + featured case study
  - Top 3 teams: featured on covenai.co and in a video

Rules:
  - Public repos: must have JitNeuro artifacts visible (CLAUDE.md, engrams, or commands)
  - Private repos: publish a "story" (blog post, video, or social post showing your build)
  - Stories earn 25 bonus points and count as a challenge entry

Teams create accountability. Choose your team wisely.
```
